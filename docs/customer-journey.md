# Customer journey

1. Choose a game and package.
2. Enter the player ID and zone when required. A completion check indicates input format, not verification with the game publisher.
3. Review the cart. Supported items display their crypto price; unavailable items are excluded from payment.
4. Confirm the details and choose a supported coin/network. Checkout displays the QR, exact amount, and payment expiry on the same page.
5. After sending payment, submit the transaction reference for review.
6. The owner verifies the payment and manually fulfills the order. The customer can follow its status.

## When something needs attention

- An unavailable package does not silently become a different product.
- Multiple eligible packages currently have separate payments; a customer can have one unfinished direct payment at a time.
- An expired amount must not be used as a current quote. Follow the order instructions or contact support.
- A transaction reference is a review request, not proof that payment was received.

This overview describes the flow. Use the live site for current product availability and payment instructions.
